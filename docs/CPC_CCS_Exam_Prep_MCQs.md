# CPC & CCS Exam Preparation - Multiple Choice Questions

## For CPC (AAPC) and CCS (AHIMA) Certification Exams

---

## ICD-10-CM Coding - Multiple Choice Questions

### Section 1: Coding Conventions

**Q1. What does the abbreviation "NEC" mean in ICD-10-CM?**
a) Not Enough Code
b) Not Elsewhere Classifiable
c) Not Elsewhere Coded
d) Not Essentially Classified

**Answer: b) Not Elsewhere Classifiable**
Explanation: NEC means the condition is not classified elsewhere and directs you to an "other specified" code.

---

**Q2. A patient has a fracture requiring a 7th character. What does the 7th character "A" represent?**
a) Aftercare
b) Active treatment
c) Initial encounter
d) Admitted patient

**Answer: c) Initial encounter**
Explanation: "A" = initial encounter for the condition, during active treatment phase.

---

**Q3. What is the difference between Excludes1 and Excludes2 notes?**
a) Excludes1 means conditions can coexist; Excludes2 means they cannot
b) Excludes1 means conditions cannot coexist; Excludes2 means they can
c) There is no difference
d) Excludes1 is for inpatient; Excludes2 is for outpatient

**Answer: b) Excludes1 means conditions cannot coexist; Excludes2 means they can**
Explanation: Excludes1 = mutually exclusive. Excludes2 = "not included here" but patient may have both conditions.

---

### Section 2: COPD & Respiratory Diseases

**Q4. A patient is admitted with "COPD with acute exacerbation." What is the correct ICD-10-CM code?**
a) J44.0
b) J44.1
c) J44.9
d) J44.8

**Answer: b) J44.1**
Explanation: J44.1 specifically identifies COPD with acute exacerbation.

---

**Q5. Which statement about acute exacerbation is TRUE?**
a) It represents a new disease process
b) It means the chronic condition has worsened
c) It is coded separately from the chronic condition
d) It is never coded for COPD

**Answer: b) It means the chronic condition has worsened**
Explanation: Exacerbation is a worsening or decompensation of a chronic condition.

---

**Q6. Patient has COPD and separate diagnosis of asthma. How should this be coded?**
a) Code only COPD (J44.9)
b) Code only asthma
c) Code both COPD (J44.x) and asthma (J45.x)
d) Cannot code both - use J44.89

**Answer: c) Code both COPD (J44.x) and asthma (J45.x)**
Explanation: These are separate conditions that can coexist (Excludes2 relationship).

---

### Section 3: Diabetes Mellitus

**Q7. Patient has "diabetes with diabetic nephropathy and peripheral neuropathy." Type not documented. What codes should be assigned?**
a) E11.21, E11.40
b) E10.21, E10.40
c) E11.9, N08.3, G63
d) E11.21 only

**Answer: a) E11.21, E11.40**
Explanation: When type not documented, default to type 2 (E11). Code both nephropathy (.21) and neuropathy (.40).

---

**Q8. For a patient with Type 1 diabetes in DKA (diabetic ketoacidosis), what is the correct code?**
a) E10.10
b) E10.11
c) E11.10
d) E10.9 + E87.2

**Answer: a) E10.10**
Explanation: E10 = Type 1 diabetes. E10.10 includes DKA (with coma E10.11). Don't code acidosis separately.

---

**Q9. Patient has diabetes "due to chronic pancreatitis." Which category should be used?**
a) E08 - Diabetes due to underlying condition
b) E09 - Drug or chemical induced
c) E10 - Type 1
d) E11 - Type 2

**Answer: a) E08 - Diabetes due to underlying condition**
Explanation: E08 is used when diabetes is due to an underlying condition. Code underlying condition (pancreatitis) first.

---

### Section 4: Injuries & External Causes

**Q10. Which 7th character represents "subsequent encounter for routine healing"?**
a) A
b) D
c) S
d) G

**Answer: b) D**
Explanation: D = subsequent encounter for routine healing (follow-up care).

---

**Q11. A patient fell off a ladder at home while painting, sustaining a closed fracture of the distal radius. How many codes are needed?**
a) 1 - injury code only
b) 2 - injury + 7th character
c) 3 - injury + place + activity
d) 4 - injury + cause + place + activity

**Answer: d) 4 - injury + cause + place + activity**
Explanation: Need: (1) S52.5xxA fracture code, (2) W11.xxA fell from ladder, (3) Y92.009 home, (4) Y93.H9 painting

---

**Q12. Patient has sequela (late effect) of old fracture. Which 7th character?**
a) A
b) D
c) S
d) K

**Answer: c) S**
Explanation: S = sequela, used for late effects after active healing phase.

---

### Section 5: Signs, Symptoms & General Guidelines

**Q13. When should you code signs and symptoms?**
a) Always, in addition to the definitive diagnosis
b) Only when no definitive diagnosis has been established
c) Never - they are integral to all diseases
d) Only for outpatient encounters

**Answer: b) Only when no definitive diagnosis has been established**
Explanation: Don't code signs/symptoms if they are integral to confirmed diagnosis or if more specific code available.

---

**Q14. For outpatient coding, how do you code "rule out pneumonia"?**
a) Code the pneumonia (J18.9)
b) Code the signs/symptoms (cough, fever, etc.)
c) Code "suspected pneumonia"
d) Code observation for pneumonia

**Answer: b) Code the signs/symptoms (cough, fever, etc.)**
Explanation: NEVER code "rule out," "suspected," or "probable" in outpatient. Code to highest degree of certainty.

---

**Q15. What does coding to "highest level of specificity" mean?**
a) Always use 7-character codes
b) Use most characters available for that code
c) Always use subcategory codes
d) Use ICD-10-PCS instead of ICD-10-CM

**Answer: b) Use most characters available for that code**
Explanation: If a code has 4th, 5th, 6th characters available, you must use them. Never truncate to category level.

---

### Section 6: Sequencing & Principal Diagnosis

**Q16. For inpatient coding, what is the principal diagnosis?**
a) The first condition listed in the chart
b) The most serious condition
c) The condition established after study to be chiefly responsible for admission
d) The condition the patient complained about

**Answer: c) The condition established after study to be chiefly responsible for admission**
Explanation: This is the official definition of principal diagnosis.

---

**Q17. Patient admitted for elective hip replacement but develops MI during surgery and surgery is cancelled. What is principal diagnosis?**
a) Hip condition (reason for admission)
b) Myocardial infarction (complication)
c) Either can be principal
d) Code both as equal

**Answer: b) Myocardial infarction (complication)**
Explanation: When original treatment plan not carried out, code the condition that occasioned admission (in this case, the MI caused admission to continue).

---

**Q18. For an acute condition and chronic condition, which is sequenced first?**
a) Always chronic first
b) Always acute first
c) Depends on reason for encounter
d) Alphabetical order

**Answer: c) Depends on reason for encounter**
Explanation: Sequence based on circumstances of encounter and reason for visit, not just acute vs chronic.

---

### Section 7: Combination Codes

**Q19. What is a combination code?**
a) Two codes used together
b) A single code that classifies two conditions
c) A code requiring a 7th character
d) A code from two different chapters

**Answer: b) A single code that classifies two conditions**
Explanation: Combination code = one code for two diagnoses, or diagnosis with manifestation/complication.

---

**Q20. Patient has Type 2 diabetes with diabetic chronic kidney disease, stage 3. What is correct coding?**
a) E11.22 + N18.3
b) E11.22 only
c) E11.9 + N18.3
d) E11.29 + N18.3

**Answer: a) E11.22 + N18.3**
Explanation: E11.22 is combination code for diabetes with CKD, but you still need to add N18.3 to specify CKD stage.

## CPT Coding - Multiple Choice Questions

### Section 8: Evaluation & Management (E&M)

**Q21. What are the three key components of E&M services?**
a) History, Examination, Medical Decision Making
b) Time, Complexity, Documentation
c) Chief Complaint, Assessment, Plan
d) Problem, Examination, Treatment

**Answer: a) History, Examination, Medical Decision Making**
Explanation: E&M services are based on these three key components (or time for certain services).

---

**Q22. How many levels of history are there?**
a) 2
b) 3
c) 4
d) 5

**Answer: c) 4**
Explanation: Problem Focused, Expanded Problem Focused, Detailed, Comprehensive

---

**Q23. For an established patient office visit, how many key components must meet/exceed level requirements?**
a) All 3
b) Any 2
c) Any 1
d) Depends on the service

**Answer: b) Any 2**
Explanation: Established patient requires 2 of 3 key components. New patient requires all 3.

---

### Section 9: CPT Modifiers

**Q24. What does modifier -25 indicate?**
a) Bilateral procedure
b) Significant, separately identifiable E&M service
c) Professional component only
d) Reduced service

**Answer: b) Significant, separately identifiable E&M service**
Explanation: -25 = significant, separately identifiable E&M on same day as procedure

---

**Q25. Modifier -50 is used for:**
a) Multiple procedures
b) Bilateral procedures
c) Staged procedures
d) Professional component

**Answer: b) Bilateral procedures**
Explanation: -50 indicates procedure was performed on both sides (bilateral)

## HCPCS Coding - Multiple Choice Questions

### Section 10: HCPCS Level II

**Q26. HCPCS Level II codes primarily describe:**
a) Physician services
b) Durable medical equipment and supplies
c) Inpatient procedures
d) Evaluation and management

**Answer: b) Durable medical equipment and supplies**
Explanation: HCPCS Level II covers DME, supplies, ambulance, drugs, etc. not in CPT

---

**Q27. What letter do injectable drug codes typically start with?**
a) E
b) G
c) J
d) L

**Answer: c) J**
Explanation: J codes = drugs administered other than oral method (injectable drugs)

**Q28. DME (Durable Medical Equipment) codes typically start with:**
a) A
b) E
c) K
d) L

**Answer: b) E**
Explanation: E codes = durable medical equipment

## Medical Record Coding - Practice Scenarios

### Scenario 1: Emergency Room Visit

**Documentation:**
"72-year-old male presents to ER with chest pain, radiating to left arm, onset 2 hours ago. PMH: Type 2 diabetes, hypertension. Exam reveals diaphoresis, BP 160/95. EKG shows ST elevation. Labs: Troponin elevated. Diagnosis: Acute STEMI anterior wall. Patient admitted to CCU."

**What codes should be assigned for the ER visit?**

**Answer:**
- I21.09 - STEMI involving other coronary artery of anterior wall (principal)
- R07.9 - Chest pain (symptom - MAY code as additional if documented separately)
- E11.9 - Type 2 diabetes (existing condition)
- I10 - Essential hypertension (existing condition)

---

### Scenario 2: Outpatient Diabetes Management

**Documentation:**
"Follow-up visit for Type 2 diabetes. Patient complains of burning feet bilaterally. Exam: decreased sensation both feet, no ulcers. HbA1c 8.2%. Diagnosis: Type 2 diabetes with diabetic peripheral neuropathy. Adjust medications."

**What codes should be assigned?**

**Answer:**
- E11.40 - Type 2 diabetes with diabetic neuropathy, unspecified (first-listed)
- (R20.8 - Other disturbances of skin sensation - NO, symptom integral to neuropathy)

---

### Scenario 3: COPD Exacerbation

**Documentation:**
"65-year-old female admitted with worsening shortness of breath, increased sputum production, wheezing. History of COPD. Chest X-ray: hyperinflation, no infiltrate. Sputum culture: normal flora. Given nebulizer treatments, steroids, antibiotics. Diagnosis: Acute exacerbation of COPD."

**What is the principal diagnosis?**

**Answer:**
- J44.1 - Chronic obstructive pulmonary disease with (acute) exacerbation

## Study Tips for CPC/CCS Exams

1. ✅ **Master the Official Guidelines** - Know conventions, chapter-specific rules
2. ✅ **Practice Daily** - Code actual medical records
3. ✅ **Time Management** - CPC: 150 questions in 4 hours; CCS: varies
4. ✅ **Use Your Codebooks** - Practice navigating index and tabular
5. ✅ **Know Common Scenarios** - Diabetes, COPD, injuries, E&M
6. ✅ **Understand Sequencing** - Principal vs additional diagnoses
7. ✅ **Don't Over-Code** - Code only what's documented and relevant
8. ✅ **Query When Unclear** - In real practice, always query provider
